# 📐 Atividades React

Repositório dedicado à prática e ao aprofundamento dos fundamentos do React, por meio de exercícios organizados por nível de dificuldade.

O objetivo é desenvolver autonomia na construção de interfaces, compreender os principais conceitos da biblioteca e evoluir gradualmente para aplicações mais completas.

## 🧮 Organização dos exercícios

Os exercícios são organizados em três níveis: fácil, médio e difícil.

## 📱 Tecnologias

- React
- Next.js
- JavaScript
- HTML5
- CSS3
- Git e GitHub

## 🔑 Como executar

Entre na pasta do exercício desejado e instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## 📗 Metodologia

Os exercícios são desenvolvidos progressivamente, priorizando a compreensão dos conceitos e a resolução independente dos problemas.

O repositório também funciona como um histórico da evolução prática em React.
